# ADR-001: Backend Framework Selection

## Context
The platform requires a high-performance backend to manage multi-tenant APIs, orchestrate complex Kubernetes sandbox lifecycles, run mathematical graph traversals for root cause analysis, and interface with LLM providers for structured incident synthesis.

## Problem
We need an API framework that offers asynchronous I/O, rigorous request/response data validation, rapid developer velocity, and direct interoperability with graph analysis, statistical packages, and AI SDKs without requiring fragmented polyglot microservices in the control plane.

## Decision
Adopt **FastAPI with Python 3.12+**, utilizing **Pydantic v2** for validation and **SQLAlchemy 2.x** with `asyncpg` for database operations.

## Alternatives Considered
- **Go with Gin/Chi:** Excellent concurrency and low memory overhead, but lacks native libraries for rapid graph algorithms, statistical Z-score calculations, and dynamic Pydantic schema validation for AI prompt workflows.
- **Node.js with NestJS:** Strong TypeScript ecosystem, but inferior to Python for scientific computing, graph traversal, and AI infrastructure integration.
- **Django REST Framework:** Feature-rich but heavier, synchronous by default, and less performant for async I/O than modern FastAPI.

## Advantages
- Pydantic v2 core written in Rust ensures high deserialization and serialization throughput.
- Automatic interactive documentation (OpenAPI 3.1 / Swagger) directly usable by frontend engineers and v0 generation.
- Native access to Python's AI/ML ecosystem (NetworkX, NumPy, Groq SDK).
- Asynchronous non-blocking concurrency via `uvloop`.

## Disadvantages
- Higher memory footprint per worker than Go.
- Python Global Interpreter Lock (GIL) requires multi-process worker deployments for CPU-heavy tasks.

## Consequences
All control plane domain logic will be written in Python 3.12 using strict type annotations (`mypy` enforced). Heavy CPU-bound graph operations will be offloaded to Celery background workers.

## Status
**Accepted**
