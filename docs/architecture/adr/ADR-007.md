# ADR-007: Root Cause Analysis (RCA) Architecture

## Context
When an incident is detected during a chaos experiment, multiple services alert simultaneously. For example, injecting latency into Payment Service causes Order Service connection pools to saturate, which in turn causes API Gateway to fail with 504 errors.

## Problem
How to reliably determine the true origin of failure without mistaking upstream victim symptoms for root causes, and without relying on non-deterministic LLM hallucinations.

## Decision
Implement a **Deterministic Algorithmic Root Cause Analysis Engine** that correlates three objective data dimensions:
1. **Temporal Precedence:** Which service first exhibited statistical metric deviation ($>3\sigma$ from baseline)?
2. **Trace Span Decomposition:** Across distributed traces, what was the self-time ratio versus downstream wait-time?
3. **Topology Graph Traversal:** Directed traversal from symptom nodes along dependency edges to dependency sinks.

The engine computes a mathematical confidence score ($0.0 - 1.0$) for each candidate node.

## Alternatives Considered
- **Pure LLM Prompting:** Feeding raw logs and metrics to an LLM and asking for root cause analysis. Rejected due to frequent hallucinations, context window limits, non-reproducible outputs, and inability to perform multi-hop graph math.
- **Rule-Based Static Alert Trees:** Brittle and requires manual rule authoring for every new topology.
- **Pure Statistical Correlation (Pearson/Spearman):** Correlation does not establish directional causality across microservice call graphs.

## Advantages
- Mathematically reproducible and fully explainable.
- Sub-second execution latency.
- Accurate differentiation between symptom services (high wait-time) and root cause services (high self-time).
- Completely immune to generative hallucination.

## Disadvantages
- Accuracy depends on the availability and sampling rate of distributed trace spans and metric scrapers.

## Consequences
The deterministic engine's structured output forms the single source of truth ("Evidence Pack") passed downstream to the AI explanation generator.

## Status
**Accepted**
