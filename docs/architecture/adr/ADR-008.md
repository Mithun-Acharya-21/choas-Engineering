# ADR-008: AI Provider Abstraction

## Context
While the deterministic RCA engine calculates ground-truth candidate scores and causal chains, on-call engineers require readable executive summaries, chronological failure timelines, and tailored remediation runbooks.

## Problem
We need an AI integration layer that produces strictly structured outputs, prevents hallucinations of telemetry, and avoids hard-coding the platform to a single AI vendor.

## Decision
Design an abstract **`ILLMProvider`** interface with a primary implementation for **Groq API** (using Llama-3-70B for high-throughput, low-latency structured JSON generation) and a fallback for OpenAI-compatible endpoints. The engine enforces **Pydantic schema validation** and executes a **hallucination verification filter** against the deterministic Evidence Pack before saving the report.

## Alternatives Considered
- **Direct OpenAI API Coupling:** Works well, but ties the platform to a single proprietary vendor and incurs higher latency and cost during automated test suites.
- **Local Embedded Models (e.g., small local 7B models via llama.cpp):** Can run fully offline, but inference throughput on standard developer machines without high-end GPUs is slow.
- **Unstructured Free-Text Prompts:** High risk of schema drift and unparseable JSON in frontend dashboards.

## Advantages
- Vendor independence: switch between Groq, local vLLM, and OpenAI via environment variables.
- Sub-second LLM inference via Groq's LPU architecture.
- Pydantic schema validation guarantees predictable JSON keys for UI rendering.
- Hallucination checks ensure the model never cites services or metric numbers that do not exist in the evidence pack.

## Disadvantages
- Requires external network access / API key for Groq (mitigated by mock provider for offline testing).

## Consequences
If the LLM provider fails or times out, the platform falls back gracefully, presenting the complete deterministic findings directly to the user without blocking the incident workflow.

## Status
**Accepted**
